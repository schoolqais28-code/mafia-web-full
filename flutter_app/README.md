# MAFIA Flutter App

Flutter/Dart Android application connected to:

https://mafia-web-admin-production.up.railway.app/

The app uses an embedded WebView so it shares the same accounts, sessions, game rooms, settings, admin page and Railway backend as the website.

## Features
- Flutter / Dart
- Persistent website cookies and login sessions
- Microphone permission for in-room voice
- WebRTC permission support inside the WebView
- Pull to refresh
- Android back-button navigation
- Offline/error screen with retry
- Uses the same live Railway website, so website updates appear in the app automatically
